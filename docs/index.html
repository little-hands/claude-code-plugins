cozy-doc — 出力サンプル

Claude Code プラグイン cozy-doc の 2 スキルが、実際に何を吐くか。どちらも 1 ファイルで完結する HTML で、生成後はブラウザで開かれます。

差分を読む順に並べた解説 /cozy-doc:diff-guide

丸め方針とレートのキャッシュを入れた 6 ファイルの差分を、依存の順（型 → それを作る側 → それを使う側 → 配線）に並べ替えたもの。

  • 各節の頭に「なぜ今これを読むのか」が 1 文ある
  • diff は全文を貼らず、落とした部分は「何を落としたか」を書く
  • 削除されたファイル・探しても無いものを先に断る
  • 読まなくていいファイルを、理由つきで名指しする

シーケンス図＋矢印ごとの実値 /cozy-doc:seq-values

$29.99 の商品ページを開いてから「4766 JPY」が出るまでを、図（流れ）と実値（中身）を別セクションに分け、矢印番号で対応させて説明したもの。

  • 図には数値を入れない（両方に置くと片方だけ古くなる）
  • 1 本のシナリオで通す
  • うまくいかない例を必ず入れる（ここでは取り扱いのない通貨）
  • 広い画面では左に図・右に実値。図は貼り付いたまま実値だけスクロールする

題材はどちらも架空の為替換算デモです。 ただし数字は推測で埋めていません — 動く実装をこしらえ、テストとコマンドを実行した出力から取っています。実在のサービス・顧客データは含みません。

スキル本体とインストール方法は little-hands/claude-code-plugins（/plugin marketplace add little-hands/claude-code-plugins）。
