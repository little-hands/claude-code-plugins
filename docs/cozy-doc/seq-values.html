ドル価格を円で見せるまで — 図と実値

$29.99 の商品ページを開いてから「4766 JPY」が出るまでを、矢印ごとの実際の値で追う。値はすべて実行して取ったもので、推測で埋めた数字は無い。

  • 矢印に番号を振り、実値も同じ番号で並べる
  • 1 本のシナリオで通す（節ごとに例を変えない）
  • うまくいかない例を必ず入れる（ここでは取り扱いのない通貨）

ユーザーストーリー

海外通販を使う買い物客として、
$ 表記の商品を、今日のレートで円換算して見たい。
カードの請求が来るまで日本円でいくらか分からない、を避けたいから。

この先の図が描いているもの — 商品ページを 1 回開いて、円価格が 1 つ出るまで。カート・決済・ログインは含まない。レートの提供元との通信も含まない（固定のレート表を引く形にしてある）。

決めごと（数字の根拠は 2. で実値と一緒に見せる）

手数料換算額に 2% 乗せる。レートに掛けるのではなく、円換算したあとの額に掛ける
丸め既定は切り上げ（1 円未満の端数を店側が負担しない）。呼び出し側が切り捨ても選べる
レートの有効期限600 秒。最後に取った時刻からの経過がこれ未満なら控えを使う
取り扱いのない通貨0 円や未定義を返さず例外にする。コマンドは終了コード 2 で終わる
計算の型すべて Decimal。float を混ぜない（丸める前の額が 2 進で表せず、境界で 1 円ずれるため）

円価格を求める — 何を渡すか

fx/cli.py · main() → fx/converter.py · to_jpy()

買い物客が開いたのは $29.99 の商品ページ。そこから換算処理へ渡すのは金額と通貨コードだけ。丸めの向きと時刻は既定値に任せる。画面側が丸めを意識しなくて済むよう、既定を持たせてある。

to_jpy(Decimal("29.99"), "USD")
#   mode = Rounding.CEIL   ← 既定（切り上げ）
#   now  = None            ← 既定（現在時刻を使う）
3

レートを問い合わせる — 時刻も一緒に渡す

fx/converter.py · to_jpy() → fx/rate_client.py · fetch_rate()

時刻を引数で受けるので、期限をまたいだ挙動を待たずに確かめられる。以下は 1757400000.0（= 基準時刻）を渡した実行。

fetch_rate("USD", now=1_757_400_000.0)

5

控えが無いので表を引き、控える

fx/rate_client.py · fetch_rate()

初回なので控えは空。レート表を引いた値を取得時刻と組で控え、どちらから来たかを示す印（miss）と一緒に返す。

#   1 回目の戻り
(Decimal("155.80"), "miss")

#   控えの中身
_cache["USD"] = (Decimal("155.80"), 1757400000.0)
4a

2 回目以降は控えを使う — 切れ目は 600 秒

fx/rate_client.py · fetch_rate()

同じ通貨をもう一度引いたときの分かれ目。600 秒未満なら控え、超えたら取り直し。境界は「未満」なので、ちょうど 600 秒は取り直す側に入る。

#   +120 秒 → 120 < 600 なので控えを使う
fetch_rate("USD", now=1_757_400_120.0)
  → (Decimal("155.80"), "hit")

#   +900 秒 → 900 ≧ 600 なので取り直す
fetch_rate("USD", now=1_757_400_900.0)
  → (Decimal("155.80"), "miss")   ← 4b へ戻る

この取り直しは失敗ではない — 控えが古くなった stale 状態を、黙って使わずに引き直しているだけ。

手数料を乗せる — 掛ける順番が結果を決める

fx/converter.py · to_jpy()

先に円換算し、そのあとで 2% を掛ける。丸める前の額は小数 6 桁まで残る。ここで丸めないのが肝で、途中で丸めると 7. の向きの指定が効かなくなる。

gross = amount * rate * (Decimal("1") + FEE_RATE)
#   ① 円換算     29.99 × 155.80     = 4672.4420
#   ② 手数料 2%  4672.4420 × 1.02   = 4765.890840

取り扱いのない通貨 — 0 円を返さず止める

fx/rate_client.py · RateUnavailable → fx/cli.py · main()

レート表に無い通貨は、例外にして上まで素通しする。途中で 0 円や「レート 1.0」に倒すと、買い物客には正しい値段に見えてしまう。コマンドは標準エラーへ 1 行出し、終了コード 2 で終わる。

to_jpy(Decimal("29.99"), "BRL")
#   → RateUnavailable   currency="BRL"   args=('BRL',)

$ python3 fx/cli.py 29.99 BRL
#   標準エラーへ:
取り扱いのない通貨です: BRL
#   終了コード 2

画面に出るのは通貨コードだけ。例外クラス名・ファイルパス・レート表の中身は出していない。
