# modeling

システムの振る舞いを、解釈の余地なく説明するためのモデリング補助プラグイン。

## 機能

現在は `seq-values` スキルを収録しています。

### seq-values — シーケンス図＋矢印ごとの実値

普通のシーケンス図は「API を呼ぶ」という形までしか語らず、戻り値のどこを使うか・丸めをどちらに倒すかは読み手の解釈に委ねられます。このスキルは、**図（流れ）と実値（中身）を別セクションに分け、矢印番号で対応させる**ことで、その余地を無くします。

**守る原則は 3 つ:**

1. 矢印に番号を振り、実値も同じ番号で並べる
2. 1 本のシナリオで通す（節ごとに例を変えない）
3. うまくいかない例を必ず入れる

対象は会話の文脈（直近で読んだコード・議論した設計・調査結果）から判断し、実コードがあれば先に読んでから実際の値（レスポンス JSON、SQL の行、計算式など）を拾います。実値をでっち上げることはありません — 裏が取れない値は「未確認」と明示するか、そもそも生成を見送ります。

**出力形式は 2 つ:**

| 引数 | 出る物 |
|---|---|
| なし / `html`（既定） | スタンドアロン HTML 1 枚。**広い画面では左に図・右に実値の 2 カラム**になり、図が貼り付いたまま実値だけスクロールする（狭い画面では縦積み）。図はズームボタンとクリック拡大つき。生成後ブラウザで自動的に開く |
| `md` | 貼り込み用の Markdown。**図と矢印ごとの実値だけ**を出す（スコープや決めごとは落とす）。GitHub・Obsidian などが mermaid をそのまま描画する |

出力先の既定はどちらも `/tmp` ですが、置き場所を指示すればそこに書きます（「この設計書に足して」など）。外部 CDN は mermaid の描画にのみ使用します。

## 前提条件

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) CLI が利用可能であること

## インストール

ターミナルで `claude` を起動し、以下のコマンドを実行してください。

```
/plugin marketplace add little-hands/claude-code-plugins
/plugin install modeling@little-hands
```

> **プラグインが見つからない場合:** マーケットプレイスが登録済みでもプラグインが見つからない場合は、マーケットプレイスの更新が必要です。
>
> 1. `/plugin` を実行
> 2. **Marketplaces** タブを選択
> 3. **little-hands** を選択
> 4. **Update** を選択
>
> 更新後、再度 `/plugin install modeling@little-hands` を実行してください。

### 自動更新の設定（推奨）

プラグインを常に最新の状態に保つため、マーケットプレイスの自動更新を有効にしてください。

1. `/plugin` を実行
2. **Marketplaces** タブを選択
3. **little-hands** を選択
4. **Enable auto-update** を選択

## 使い方

会話の文脈から自動で発動します（「シーケンス図でHTML作って」「処理の流れを実値つきで説明して」「フローをHTMLにまとめて」などのフレーズ、または `seq-values` という語）。明示的に呼びたい場合は `/seq-values` を使ってください。

```
/seq-values          # HTML（既定）
/seq-values md       # 貼り込み用の Markdown
```

同名の他のコマンドがある場合は、名前空間付きの `/modeling:seq-values` で呼び出してください。

**使わない場面:**

- 図だけ欲しい時（mermaid のコードブロックだけで足りる）
- `.drawio` ファイルが欲しい時
- 実値の裏取りができない時（推測値で埋めることはしません）
